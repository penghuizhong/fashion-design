# 方圆智设 · AI 服装设计平台

> 重塑时尚生态 · AI 驱动服装设计革新

方圆智设是一款面向服装设计师与品牌的 AI 服装设计全链路数字化工作台，整合顶级生成式时尚大模型，从灵感草图、3D 生成、AI 模特走秀到电商大片，提供一站式设计解决方案。

## ✨ 核心功能

- **AI 创款** — 从设计理念/草图一键生成高定款式效果图，支持文生款、相似款、款式融合、系列创款
- **AI 改款** — 智能修改服装颜色、领型、袖型、裙长、廓形、面料、风格等
- **AI 视觉** — 虚拟试衣、AI 换模特、场景生成、商业摄影、图生视频走秀
- **AI 工具** — 图片褪底、高清放大、涂抹消除、语音设计、语音克隆等效率工具
- **趋势洞察** — 全球时装周趋势解析、流行色/面料/廓形/细节趋势研判
- **我的工作台** — 统一管理所有设计项目、收藏与历史记录

## 🧵 双平台联动

方圆智设（AI 服装设计）与 [**方圆智版**](https://zhiban.fangyuan-ai.com)（AI 服装制版）深度打通，设计稿一键转版型参数，实现从创意灵感、效果渲染到工业制版的全链路数字化协同。

| 平台 | 定位 | 核心能力 |
|------|------|----------|
| 方圆智设 | 服装设计端 | AI 创款、改款、视觉、趋势 |
| 方圆智版 | 制版生产端 | CAD 图稿库、公式计算器、AI 制版助手、制版教程 |

## 🎨 主题切换

支持一键切换深色 / 浅色主题，点击右上角主题按钮即可切换。

- 🌙 **深色模式** — 沉浸式设计体验，默认开启
- ☀️ **浅色模式** — 暖米色调，清爽护眼

## 🛠 技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **路由**: Vue Router
- **图标**: Lucide Vue Next

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

